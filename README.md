# Book of Leprus

WebApp mobile demo di slot parodistica con crediti finti.

## Come usarla
Apri `index.html` da browser mobile o desktop. Non richiede server.

## Funzioni incluse
- 5 rulli x 3 righe
- 10 linee di pagamento
- Puntata regolabile
- Auto spin
- Wild
- Scatter/Bonus con la prima foto
- Free Spins con simbolo espandibile
- Mini game “Tempio del Leprus” con 5 porte
- Audio sintetico attivabile/disattivabile
- Salvataggio crediti in localStorage
- Layout mobile portrait 9:16

## Nota
È solo una demo scherzosa. Non usa denaro reale e non è collegata a sistemi di pagamento.
